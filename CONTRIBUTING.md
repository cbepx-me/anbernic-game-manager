# Contributing to Anbernic Game Manager

We welcome contributions! Please follow these guidelines to keep the project healthy.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Make your changes** – please keep code style consistent (PEP 8 for Python).
3. **Test** your changes on an Anbernic device (or simulation) to ensure they work.
4. **Commit** with a clear message describing what you did.
5. **Open a Pull Request** – explain your changes and why they are useful.

## Reporting Issues

- Use the [Issue Tracker](https://github.com/yourusername/anbernic-game-manager/issues)
- Provide as much detail as possible: device model, firmware version, steps to reproduce.

## Code Style

- Python: follow [PEP 8](https://www.python.org/dev/peps/pep-0008/).
- HTML/JS: keep it readable and consistent with existing files.

## Translations

Translations are in `lang/*.json`. To add a new language, copy an existing file and translate the values.

Thank you for helping improve this project!

# 贡献指南（中文）

欢迎贡献代码！请遵循以下准则以保持项目健康。

## 如何贡献

1. **复刻（Fork）仓库**，并从 `main` 分支创建您的分支。
2. **进行修改** – 请保持代码风格一致（Python 遵循 PEP 8）。
3. **测试**您在 Anbernic 设备上的更改（或模拟环境），确保功能正常。
4. **提交**时附带清晰的提交信息，描述您所做的更改。
5. **打开拉取请求（Pull Request）** – 说明您的更改及其有益之处。

## 报告问题

- 使用 [问题跟踪器](https://github.com/yourusername/anbernic-game-manager/issues)
- 尽可能提供详细信息：设备型号、固件版本、重现步骤。

## 代码风格

- Python：遵循 [PEP 8](https://www.python.org/dev/peps/pep-0008/)。
- HTML/JS：保持可读性，并与现有文件风格一致。

## 翻译

翻译文件位于 `lang/*.json`。要添加新语言，请复制现有文件并翻译其中的值。

感谢您帮助改进此项目！
